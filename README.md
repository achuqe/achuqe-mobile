# აჩუქე

**„აჩუქე“** არის ქართულენოვანი მობილური პლატფორმა, რომელიც მომხმარებელს კონკრეტული ადამიანის, შემთხვევის, ასაკის, ინტერესებისა და ბიუჯეტის მიხედვით ურჩევს საჩუქრებს. აპლიკაციის მეორე მხარე განკუთვნილია ბიზნესებისთვის, რომლებსაც შეუძლიათ შექმნან პროფილი, დაამატონ პროდუქტები და მიუთითონ მათი სამიზნე შემთხვევები და აუდიტორია.

## პირველი ვერსიის შესაძლებლობები

| მიმართულება | განხორციელებული ფუნქციები |
|---|---|
| მომხმარებლის გამოცდილება | მისალმება, ანგარიშის ტიპის არჩევა, OAuth რეგისტრაცია/შესვლა და დემო რეჟიმი |
| საჩუქრის შერჩევა | ხუთსაფეხურიანი კითხვარი, ბიუჯეტის ფილტრაცია, წონიანი შესაბამისობის ქულა და მიზეზების ახსნა |
| კატალოგი | პროდუქტის ძიება, ინტერესით ფილტრაცია, დეტალური გვერდი, გაზიარება და რჩეულები |
| ბიზნესის სივრცე | ბიზნეს-პროფილი, მიმოხილვის დაფა, პროდუქტის დამატება/რედაქტირება და სტატუსის მართვა |
| მედია | გალერეიდან 4:5 ფოტოს არჩევა, ზომის შემოწმება და ავტორიზებული ატვირთვა სერვერულ საცავში |
| მონაცემები | MySQL/Drizzle სქემა მომხმარებლებისთვის, ბიზნესებისთვის, პროდუქტებისთვის, რჩეულებისა და ძიების ისტორიისთვის |
| საიმედოობა | ოფლაინ სარეზერვო შენახვა AsyncStorage-ში, სერვერული სინქრონიზაცია ანგარიშით და ავტორიზებული tRPC API |

## ტექნოლოგიური სტრუქტურა

აპლიკაცია აგებულია **Expo SDK 54**, **React Native**, **Expo Router**, **TypeScript**, **NativeWind**, **tRPC**, **Drizzle ORM** და **MySQL** ტექნოლოგიებზე. მომხმარებლის ავტორიზაცია მუშაობს OAuth ნაკადით: web გარემოში გამოიყენება დაცული cookie, ხოლო iOS/Android-ზე session token ინახება SecureStore-ში.

რეკომენდაციის პირველი ძრავა გამჭვირვალე წესებზეა დაფუძნებული. შემთხვევა, ასაკი, სქესი, ურთიერთობა, ინტერესები და ბიუჯეტი სხვადასხვა წონით ზრდის პროდუქტის ქულას. შედეგები იფილტრება მაქსიმალური ბიუჯეტით, შემდეგ კი შესაბამისობის ქულისა და ფასის მიხედვით ლაგდება. საერთო ძრავა გამოიყენება როგორც მობილურ ინტერფეისში, ისე სერვერულ API-ში.

## ძირითადი საქაღალდეები

| მდებარეობა | დანიშნულება |
|---|---|
| `app/` | Expo Router ეკრანები და მომხმარებლის/ბიზნესის ნაკადები |
| `components/` | ბრენდის, ღილაკების, პროდუქტებისა და ბიზნესის საერთო კომპონენტები |
| `data/` | დემო კატალოგი და კითხვარის ვარიანტები |
| `lib/` | აპის მდგომარეობა, API კლიენტი, ჰაპტიკა და დამხმარე ლოგიკა |
| `shared/` | საერთო TypeScript მოდელები და რეკომენდაციის ძრავა |
| `server/` | tRPC API, მონაცემთა ბაზის ოპერაციები, OAuth და ფაილების საცავი |
| `drizzle/` | მონაცემთა ბაზის სქემა და მიგრაციები |
| `tests/` | რეკომენდაციისა და API ავტორიზაციის Vitest ტესტები |

## ლოკალურად გაშვება

დამოკიდებულებების დაყენების შემდეგ გამოიყენეთ `pnpm dev`. TypeScript-ის შესამოწმებლად გაუშვით `pnpm check`, კოდის სტილისთვის — `pnpm lint`, ხოლო ერთეული ტესტებისთვის — `pnpm test`.

## პირველი ვერსიის საზღვრები

მიმდინარე ვერსია მოიცავს პროდუქტის სრულ დემონსტრირებად ნაკადს და ანგარიშით სერვერულ სინქრონიზაციას. უშუალო საბარათე გადახდა, კურიერის ინტეგრაცია, მომხმარებელსა და ბიზნესს შორის რეალურ დროში ჩატი, რეიტინგები და ადმინისტრატორის ცალკე moderation პანელი განზრახ დარჩენილია მომდევნო ვერსიებისთვის.

## ხარისხის მდგომარეობა

პროექტი წარმატებით გადის TypeScript-ის, ESLint-ისა და Vitest-ის შემოწმებებს. ავტომატური ტესტები ფარავს რეკომენდაციების დალაგებას, ბიუჯეტის ფილტრაციას, არააქტიური პროდუქტების გამორიცხვას, ანონიმური წვდომის დაბლოკვას და პროდუქტის მფლობელობის კონტროლის გადაცემას მონაცემთა ფენაზე.
